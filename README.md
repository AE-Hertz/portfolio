# 🚀 Developer Portfolio Template

A modern developer portfolio built with a clean UI, responsive design, and smooth animations. This project is open for contributions and intended to help beginner developers learn real-world collaboration through open source.

---

# 🌟 Goal of This Project

This repository is being maintained as an open-source contribution project for **GirlScript Summer of Code 2026 (GSSoC'26)**.

The aim is to:

* Help beginners make their first open-source contribution
* Provide a portfolio starter template for developers
* Encourage learning through real-world collaboration
* Improve frontend development skills
* Build a friendly contributor community

Contributors can improve this portfolio and later use the knowledge to create and customize their own portfolio websites.

# ⚙️ Getting Started

## 1️⃣ Clone the repository

```bash
git clone https://github.com/AE-Hertz/portfolio.git
```

## 2️⃣ Navigate into the project

```bash
cd portfolio
```

## 3️⃣ Install dependencies

```bash
npm install
```

## 4️⃣ Start development server

```bash
npm run dev
```

# 🤝 Contribution Guidelines

We welcome contributions from everyone, especially beginners participating in GSSoC'26.

## How to Contribute

1. Fork the repository
2. Create a new branch

```bash
git checkout -b feature-name
```

3. Make your changes
4. Commit your changes

```bash
git commit -m "Added new feature"
```

5. Push to your fork

```bash
git push origin feature-name
```

6. Open a Pull Request
